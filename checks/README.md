# Проверки

Независимые проверки утверждений книги Х. Роджерса «Теория рекурсивных функций
и эффективная вычислимость» (Мир, 1972). Они дополняют, но не заменяют чтение
текста: каждая программа проверяет только перечисленные в ней случаи в
указанных границах, а не общие утверждения. Где текст книги исправлен,
напечатанное чтение оставлено в программе как опровергаемая проверка рядом с
исправленным.

## Тесты

`checks/tests` — тесты, которые запускают `just test` и `just check`:
нумерация книги (`test_numbering.py`), литература из `references.bib` и
страницы упоминаний (`test_bibliography.py`), указатели (`test_index.py`),
переносы ссылок (`test_reference_wrapping.py`), отметки страниц
(`test_source_scope.py`) и записи `lean-proofs.json` (`test_lean.py`).

## Lean

`checks/lean/RogersRecursive/*.lean` — доказательства отдельных ограниченных
шагов в Lean 4; места текста, к которым они относятся, — в
`checks/lean-proofs.json`. `just check-lean` компилирует их и проверяет, что
используются только стандартные аксиомы.

Главы 1–4 (`Ch01_04*.lean`, только собранные модули mathlib, без
`Mathlib.Computability`): функция Аккермана — уровни 0–2 и неформальное
описание при x ≥ 1 (§ 1.2); схема для λx[2x] и пункт (iv) в ее последней
строке, указание к упр. 2-1; диагональные рассуждения гл. 1–2 — теоремы 1-VII
(оба доказательства), 1-VIII, следствие 1-VII, теорема Райса, теоремы 2-II и

(теорема I), теорема II и теорема III со следствиями.
